# 剪映批量剪辑工作台使用说明

这份压缩包用于在当前电脑上完成草稿读取、素材管理、批量生成和剪映导出。程序已经包含运行环境，不需要安装 Python、Anaconda，也不需要输入命令。

## 使用前准备

1. 使用 Windows 10 或 Windows 11 电脑。
2. 电脑上已经安装可正常使用的剪映专业版。
3. 需要导出视频时，不要锁屏，也不要同时手动操作剪映。
4. 把整个 ZIP 解压到一个固定文件夹，不要直接在压缩包里运行，也不要只复制 EXE。

正式完整包在构建时已经写入数字人网站公网地址，并包含交付时确认的公共音乐、字体及其他
素材库。安装后无需手工修改服务器地址；若使用更新包覆盖旧安装，原有 `data` 和连接配置
仍按更新包规则保留。

## 精确字幕 ASR

字幕精确校准默认使用本机 `http://127.0.0.1:18084` 的 CPU FunASR。工作台启动时会先复用已经运行的兼容服务；完整包内存在 `asr_runtime` 时会自动静默启动，关闭工作台时自动结束。模型只提供字词时间，不改写脚本，也不决定断句。

完整打包时，把 `runninghub_mvp/media_node/build-portable-media-node.ps1` 生成并展开的完整便携运行时传给：

```powershell
.\scripts\build\build_processor.ps1 -AsrBundleRoot "D:\path\to\expanded-rh-media-full"
```

第一次完整安装需要携带约 1 GB 模型和 CPU 推理依赖；以后的 `-UpdateOnly` 代码更新不会重复携带该运行时。若未内置，工作台仍可复用电脑上已经运行的 18084 服务，但生成精确字幕时不会静默退回旧的等字数插值。

## 第一次打开

1. 双击 `JianyingRenderServer.exe`。
2. 如果 Windows 询问是否允许网络访问，选择允许“专用网络”。
3. 稍等片刻，浏览器会自动打开“剪映批量剪辑工作台”。
4. 启动后会保留一个黑色运行窗口。使用期间不要关闭它；关闭窗口就等于停止工作台。

以后仍然只需要双击 `JianyingRenderServer.exe`。

## 页面上的四个入口

### 上传草稿

把这台电脑上已经剪好的剪映草稿读取为母版。草稿采集功能已经集成在工作台中，启动工作台后可以直接选择草稿、分析并上传，不需要再打开第二个 EXE。

### 生成视频

选择一个母版或一个视频，设置音乐、特效、字体、画面变化和封面，然后开始生成。工作台会依次控制剪映导出，完成后可以预览、下载或打开所在文件夹。

### 批量任务

一次选择多个母版，统一设置参数，再批量生成。剪映一次只能稳定导出一个任务，因此任务会自动排队，不需要反复点击。

### 素材管理

管理当前电脑上的母版、音乐、特效、字体、花字和贴纸。可以停用、恢复或删除素材。删除后会进入工作台回收站，保留 7 天后再自动清理实际文件。

## 本机处理和其他工作台

- `本机处理`：直接使用当前电脑上的视频、草稿和剪映，不上传原视频。
- `其他工作台`：把任务交给另一台专门用于剪映导出的电脑。

第一次使用其他工作台时，点击“管理其他工作台”，把负责人发来的地址逐行粘贴进去。页面会显示每台工作台是空闲、忙碌还是离线；点击“其他工作台”时，会自动打开在线且任务最少的一台。程序不再预设任何固定电脑。

如果负责人发来的是 `打开公用工作台.url`，直接双击这个文件即可，不需要填写地址。

## 正常结束

1. 等待当前导出完成。
2. 确认任务页面没有正在运行的任务。
3. 关闭工作台的黑色运行窗口。

强制关机或在导出过程中关闭程序，当前任务可能失败，但已经完成的视频不会受影响。

## 常见问题

### 双击后网页没有打开

先看黑色运行窗口是否仍然存在。如果存在，在浏览器打开：

`http://127.0.0.1:8010/app/new`

### 页面显示工作台离线

说明 `JianyingRenderServer.exe` 没有运行，或者运行窗口已经被关闭。重新双击启动即可。

### 剪映反复抢占鼠标和窗口

这是自动导出的正常过程。导出电脑在工作期间应专门用于该任务，不要同时操作剪映。

### 导出失败或一直不动

1. 确认剪映可以正常手动打开和导出。
2. 确认电脑没有锁屏。
3. 关闭剪映和工作台后重新启动，再重试失败任务。
4. 仍然失败时，把 `data\logs\server.log` 发给维护人员。

### 换新版程序会不会丢素材

不会。更新时使用更新包覆盖程序文件，不要删除原目录里的 `data` 文件夹。`data` 中保存了素材、母版、任务记录和设置。

## 重要文件

- 程序：`JianyingRenderServer.exe`
- 素材和母版：`data`
- 日志：`data\logs\server.log`
- 本机设置：`data\processor_config.json`

日常使用不需要修改这些文件。迁移电脑或备份时，保存整个程序目录最稳妥。
