# 剪映处理电脑接入说明

这个压缩包只用于增加执行剪映导出的电脑。普通使用者不需要安装它。

## 使用前准备

1. 先由负责人启动“公用剪映工作台”。
2. 当前电脑安装了可正常导出的剪映专业版。
3. 关闭自动休眠，运行期间不要锁屏。
4. 向负责人索取两项内容：`工作台地址`和`接入密码`。

程序已经包含运行环境，不需要安装 Python、Anaconda，也不需要输入命令。

## 第一次接入

1. 完整解压 ZIP。
2. 双击 `JianyingRenderAgent.exe`。
3. 给这台电脑选择一个名称，例如“一号处理电脑”。
4. 在“工作台地址”中粘贴负责人提供的地址。
5. 在“接入密码”中粘贴负责人提供的密码。
6. 确认剪映草稿目录；自动识别正确时不需要修改。
7. 点击“保存并启动”。

设置会自动保存。以后只需双击程序并点击启动。

## 怎么判断连接成功

启动窗口会显示已经连接，公用工作台顶部也会显示在线处理电脑数量。每台电脑同一时间执行一个任务，多台电脑会自动分担队列，不需要手动指定任务。

## 使用期间注意

- 保持剪映登录和桌面解锁。
- 不要同时人工操作剪映。
- 不要退出启动器。
- 电脑可以处理其他后台工作，但不建议进行会抢占鼠标、键盘或剪映窗口的操作。

## 连接失败

1. 确认这台电脑与公用工作台电脑连接的是同一个可互相访问的网络。
2. 重新向负责人复制工作台地址和接入密码，避免多出空格。
3. 确认公用工作台仍在运行。
4. 如果更换了公用工作台电脑，使用负责人最新发来的连接信息。

## 重新设置

重新打开程序，修改工作台地址、接入密码或草稿目录，再点击“保存并启动”即可。配置保存在：

`%LOCALAPPDATA%\JianyingRenderAgent\config.json`
