# 公用剪映工作台快速启用说明

这个压缩包用于把一台 Windows 电脑变成团队共用的剪映工作台。普通使用者只需要打开负责人发来的快捷文件，不需要理解电脑地址或端口。

## 负责人第一次启用

1. 选择一台长期用于剪映导出的 Windows 电脑。
2. 安装并登录剪映专业版，关闭自动休眠。
3. 完整解压本 ZIP 到固定目录。
4. 双击 `JianyingRenderServer.exe`。
5. Windows 询问网络权限时，允许“专用网络”。
6. 启动成功后，程序目录会自动出现：
   - `打开公用工作台.url`
   - `公用工作台连接说明.txt`

## 发给普通使用者

把 `打开公用工作台.url` 发给使用者。对方双击即可打开网页，不需要自己填写电脑地址。

对方需要读取自己电脑上的剪映草稿时，还要在自己电脑上启动 `JianyingDraftCollector.exe`。

## 增加更多剪映处理电脑

当前推荐的简单方式，是在每台新增电脑上都部署一份本公用工作台包。每台电脑都有自己的网页、素材和任务队列。

普通使用者在本机工作台点击“管理其他工作台”，每行添加一个公用工作台地址。页面会显示每台电脑空闲、忙碌或离线，并自动打开任务最少的一台。

`JianyingRenderAgent` 是“一个中央队列连接多台纯导出电脑”的高级方案，目前日常部署不需要使用。

## 网络变化后链接失效

程序每次启动都会重新生成连接文件。如果换了路由器、网络或电脑，旧快捷文件可能失效。重新启动公用工作台，再把新生成的 `打开公用工作台.url` 发给使用者即可。

连接同一个普通 Wi-Fi 通常可以使用；访客 Wi-Fi、酒店网络和开启设备隔离的网络可能无法让电脑互相访问。

## 日常运行

- 保持公用工作台程序窗口开启。
- 执行导出的电脑不要锁屏。
- 不要在自动导出期间人工操作剪映。
- 定期备份整个 `data` 文件夹。

日志位于 `data\logs\server.log`。出现无法启动、任务卡住或导出失败时，把该文件交给维护人员。
