## 连接方式

- 工作台服务端口改为 `8010`，避免与数字人网站的 `8000` 冲突。
- 源码联调可通过环境变量连接 `http://127.0.0.1:8000`；交付给用户的 Windows 工作台
  默认连接正式数字人网站 `https://video.lanyingjk01.com`。
- 配置字段统一为 `data/processor_config.json` 中的 `digital_human_server_url`。
- Windows 工作台旧配置中的 `http://127.0.0.1:8000`、`http://192.168.11.28:8000`
  或旧云端认证地址会迁移到正式数字人网站；用户明确填写的其他 HTTPS 数字人地址不会被覆盖。
- 正式上线时只需把 `digital_human_server_url` 改为云端数字人网站 HTTPS 地址，无需迁移云端现有账号。

## 登录与管理员边界

- 普通用户在工作台输入账号密码后，由数字人网站完成验证；工作台不保存密码，只保存短期会话令牌。
- 工作台 `/admin` 不再作为普通账号管理入口，而是跳转数字人网站 `/admin`。
- 工作台独立技术管理入口保留为 `/local-admin/login`，用于素材、机器和本地运行设置。
- 数字人账号被停用、删除或修改密码后，现有工作台会话失效。

## 数字人任务收件箱

工作台新增“数字人任务”区域，每 15 秒刷新当前登录账号自己的任务。刷新只更新列表，不会自动下载、自动导入、自动渲染或自动发布。

| 数字人任务 | 工作台动作 |
| --- | --- |
| `AUTO_READY` 且 `AUTO_POSTPROCESS` | 显示“一键导入工作台”，下载唯一完整视频并载入精确字幕时间戳 |
| 上传音频任务 | 显示需要人工处理，并提供原始片段下载 |
| 文本语音被切成多个片段 | 显示需要人工处理，并提供每个原始片段下载 |

自动导入成功后会切换到视频生成页面、选中本地视频源并填入字幕。操作人仍需选择 BGM、字幕字体/样式、保存目录并确认渲染。

## 工作台新增接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/digital-human/tasks` | 拉取当前登录账号的数字人任务 |
| `POST` | `/api/digital-human/tasks/{item_id}/import` | 导入唯一的自动后期视频及精确字幕 |
| `GET` | `/api/digital-human/tasks/{item_id}/videos/{video_index}` | 下载人工处理任务的指定原始片段 |

上述接口使用工作台当前会话，并由服务端携带短期令牌访问数字人网站，不把令牌暴露给前端下载地址。

## 字幕规则

- 渲染接口支持精确字幕 cue JSON 和 SRT，能够保留数字人网站返回的开始、结束时间。
- 字幕预览使用同一套校验逻辑；重叠、逆序或无效时间段会拒绝。
- 视频尾部与最后一句字幕只存在不超过 1 秒的小误差时，会裁到视频结尾；更大的不一致会报错，避免静默错位。
- 用户编辑字幕文字或更换视频源后，已导入的精确 cue 会失效，工作台按新内容重新处理。
- 上传音频或多片段任务建议先人工粗剪，再使用剪映字幕识别和人工校对。

## 本地文件与保存目录

- 从数字人网站导入的视频作为本地媒体引用保存，不上传阿里云。
- 输出目录继续由操作人在本机选择，并使用浏览器本地存储记住上一次选择。
- 本轮未增加自动发布；完成的本地视频仍按原工作台流程交给后续服务。
