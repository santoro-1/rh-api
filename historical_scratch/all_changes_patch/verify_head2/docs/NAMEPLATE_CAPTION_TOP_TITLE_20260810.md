# 人名板、字幕与顶部固定标题开发文档

日期：2026-08-11

## 目标与基准

本功能以 1080×1920、9:16 竖屏为设计基准，解决三项统一排版问题：统一人名板、放大并上移
字幕、增加可参数化的顶部双行标题。所有位置同时用于浏览器预览、普通剪映成片和模块 6 变体。

人名板素材来自人工调整草稿 `jyd_eab56dad6e7e`；尺寸与位置按 2026-08-11 参考图重新收敛：

- 受控素材：`data/libraries/semantic_visual_library/fixed/nameplate_zhangluo/resources/sticker/singleImage.png`
- `scale=0.60`
- `transform_x=-0.40`（左边缘与画面左边缘贴齐）
- `transform_y=-0.26`（1080×1920 参考画面中心约 Y=1210）
- `opacity=1.0`，从正文第 1 帧持续到正文结束

字幕参数来自人工参考图：

- 字号 `14`
- `transform_x=0`
- `transform_y=-850/1920≈-0.44271`（1080×1920 参考参数 Y=-850）
- 最大宽度 `0.8`，单行，默认白字与黑色 `0.06` 描边
- 单行参考容量约 `10.21em`；服务端继续按实际字体 glyph advance 断句，不按固定汉字数硬切

## 顶部标题参数契约

标题来自统一内容分析的唯一两行结果：

```json
{
  "title": {
    "line_1": "减脂真相",
    "line_2": "坚持更关键"
  }
}
```

`line_1` 映射为黄色小标题，最多 5 个字符，字号 11，`transform_y=1535/1920`；`line_2` 映射为
白色主标题，新 AI 标题最多 8 个字符（历史已保存标题兼容到 14 字），字号 13，
`transform_y=1350/1920`。两行均水平居中、单行、宽度
上限 0.92、黑色 `0.04` 描边。两行禁止空白或重复。

标题分支失败或历史项目没有标题时不创建标题轨道，不出现占位文字。模型在现有一次 Ark 内容分析
调用中生成 `line_1/line_2`，不能改变字号、颜色、坐标和轨道时长，也不能另为封面生成第二套文案。

## API 与持久化

以下两个入口接受同一 `top_title` 对象：

- `POST /api/new/projects/{project_id}/postprocess/generate` 的 `items[*].top_title`
- `PATCH /api/new/projects/{project_id}/items/{item_id}/postprocess-settings` 的 `top_title`

统一分析结果保存在 `item.settings.postprocess.title`，并确定性映射为 `top_title` 与
`cover_title`。兼容 API 仍可接受旧对象，但自动链路只维护一份 canonical title。标题设置变化只使
最终后处理结果失效，不重新调用语音或 RunningHub。

## 渲染与层级

导出时服务端把非空标题转换成两个全时长 `texts` 新增项，并冻结所选字幕字体。人名板仍是
`fixed_overlays` 图片轨道。视觉层级为：基础画面/特效 < 人名板 < 所有语义图片/小窗/全屏
B-roll < 顶部标题/字幕；因此出现的贴图可遮盖人名板。封面偏移统一在正文轨道生成后处理，
标题和人名板不会显示在 3 帧封面上。

## 验收标准

1. 受控人名板素材与人工草稿启用 PNG 一致，剪映 JSON 的 scale/x 固定，y 为 `-0.18`。
2. 字幕剪映 JSON 为 14 号、Y=-780；浏览器按同一归一化坐标居中显示。
3. 字幕最大宽度保持 80%，较长脚本重新断句且任何 cue 都不换行。
4. 标题为空时没有 `texts` 标题项；非空时两条轨道覆盖完整正文，颜色、字号和 Y 坐标固定。
5. 普通导出与变体任务冻结同一标题、人名板和字幕参数；贴图轨道高于人名板。

[AI_TITLE_AND_COVER_20260810.md](AI_TITLE_AND_COVER_20260810.md)。封面属于项目后处理，不再由模块 6
逐行手工填写。
