# H3 远端缺图重试修复验收

日期：2026-08-31。范围：本地数字人服务代码；未部署生产、未创建真实 RunningHub 任务。

## 结果

针对最近一次明确的 RunningHub `LoadImage / FileNotFoundError`、远端 `openapi/*.png`
缺失，人工重试时精确定位对应图片，以不改变画面的临时 PNG 副本重新上传。
这是针对远端失效素材引用的恢复措施，不代表已查明或修复 RunningHub 内部故障。

- 有同次远程任务的上传回执时，匹配槽位和源文件 SHA-256；历史任务没有回执时只接受
  源文件 SHA-256 与远端文件名精确匹配，不猜测第一张图。
- 保留原 PNG 全部数据块并校验 CRC，只增加不可见元数据；原图、像素、颜色、透明度、
  参考顺序、提示词和冻结输入不变。同次逻辑重试保持稳定，后续远端失败再人工重试时换新标记。
- 无法确认图片、完整性校验失败、平台返回非法文件名或仍返回已知失效文件名时，
  在生成提交前停止，显示 `H3_INPUT_RECOVERY_FAILED`。不自动重复付费生成。
- 保存上传指纹及远端文件名，接受远程任务后绑定回执，远端失败时归入尝试历史。
  不记录 API Key、完整脚本、源文件绝对路径或带凭据 URL。
- 重试入口增加数据库状态/更新时间条件校验，避免重复请求覆盖已入队或已提交任务。
- 成功分段及结果文件不改；下载失败只重下、提交结果不明禁止盲目重提、旧 LTX MP4
  恢复逻辑均保留。没有新增依赖、数据库表或迁移。
