## 当前判断

1. 动作切片对展示范围的影响已被严格交叉测试确认。
2. 换衣不是动作切片单独决定，而是动作、seed 和采样轨迹的交互结果。
3. 采样步数影响很大，但不存在简单的“步数越高越稳定”。
4. 在更多样本验证前，不建议仅把生产默认步数改成 6 或 8；更有希望的方向是筛选低风险动作切片，并在重试时切换动作切片和 seed，而不是只重复相同输入。
