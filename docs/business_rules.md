# 媒体链路业务规则

- [verified] 新 OSS 接口默认 `MEDIA_OSS_ENABLED=false`；原网站、H3 和工作台生成参数/收费规则均未改变。
- [verified] 同用户、同来源、同 `upload_key` 只能绑定同类、同用途、同大小和同源 SHA-256；重复初始化返回原素材编号，冲突返回 409。
- [verified] 预声明大小按图片/音频/视频现有限额校验；用户未过期暂存总量继续受 `MAX_BATCH_TOTAL_UPLOAD_MB` 限制。分片缺失、顺序或长度不符不能合并。
- [verified] `UPLOADED` 不是 `READY`。核验 Worker 按对象流计算 SHA-256、限定临时空间，并使用 FFprobe/FFmpeg 检查媒体解码；网站复核回执中的大小、摘要和类型。无论状态如何，新 OSS 素材此阶段都尚未进入 H3/旧业务预检，不会触发 RunningHub 付费。
- [verified] 云端任务有唯一素材编号、租约与最多 3 次尝试；过期/伪造租约拒绝，暂时错误重排，最终失败标记 `REJECTED`。
- [inferred] 业务处理前还须按原合同校验时长、分辨率、ASR 和切片，再将 `READY` 素材按任务边界交给 FC；网站只在处理回执齐全后继续原费用确认与提交保护。
- [inferred] 结果归档失败只能恢复归档/下载，不应重新生成或重复付费。历史文件迁移必须保留原件直到另行确认。
