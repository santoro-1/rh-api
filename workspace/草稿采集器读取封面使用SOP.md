# 草稿采集器读取封面使用 SOP

日期：2026-09-03

## 1. 功能结论

当前剪映草稿采集器已经支持两类封面能力，两者相互独立：

1. **模板缩略图**：采集草稿中的 `draft_cover.jpg` 或 `draft_cover.png`，在“剪映模板中心”的模板卡片上展示。草稿没有该文件时显示“暂无草稿封面”，不影响模板继续使用。
2. **封面人物图槽**：分析剪映时间轴，把从第 0 帧开始、持续时间很短、只被一个普通视频轨片段引用的照片识别为可替换人物图槽。模板保存后不保留这张旧人物照片；使用模板生成视频时，自动换成当前项目生成基础视频时绑定的人物图，同时保留原片段的位置、缩放、裁剪等剪映属性。

花字、贴纸、Logo、边框、装饰图片、遮罩和特效不会被识别为封面人物图槽，仍按原草稿保留。

## 2. 使用前准备

1. 当前电脑已安装剪映专业版。
2. 目标草稿能在剪映中正常打开，并已保存完成。
3. 使用完整工作台时，按正常方式启动工作台即可；如果页面提示“本机草稿工具未启动”，再单独启动 `JianyingDraftCollector.exe`。
4. 如果浏览器访问的是另一台电脑上的公用工作台，必须在草稿所在电脑启动 `JianyingDraftCollector.exe`，并保持运行到上传结束。
5. 使用自己的数字人账号登录工作台。模板按登录账号隔离保存。

## 3. 在剪映中制作可识别的封面

1. 在普通视频轨的最前面放入一张人物照片。
2. 人物照片必须从时间轴 `00:00:00` 开始。
3. 建议将照片时长精确设置为 3 帧；工作台默认也是 3 帧。按 30 fps 计算，3 帧约为 0.1 秒。
4. 如果实际封面不是 3 帧，导入时把“模板封面长度（帧）”改成实际值，可填写 1～30 帧。
5. 这张人物照片在草稿中只使用一次。重复引用同一个照片素材时，系统不会把它自动认作人物图槽。
6. 正文主视频放在封面片段之后。标题、花字、Logo、贴纸、边框和其他装饰按正常方式放在对应轨道。
7. 保存草稿，并确认重新打开后封面排版正常。

## 4. 通过草稿采集器导入模板

1. 启动剪映批量剪辑工作台。
2. 登录后进入“剪映模板中心”。
3. 点击“从本机剪映导入”。
4. 默认采集器地址保持为 `http://127.0.0.1:8765`。
5. 点击“扫描草稿”。
6. 在“选择草稿”中选择刚保存的剪映草稿。
7. 填写保存到当前账号的模板名称。
8. 在“模板封面长度（帧）”中填写与剪映封面片段一致的帧数；通常保持默认 `3`。
9. 点击导入按钮，等待以下四步全部完成：
   - 解密并分析草稿资源；
   - 生成模板中心上传清单；
   - 申请当前账号的一次性上传凭证；
   - 打包并上传模板资源。
10. 页面提示“模板导入完成”后，在模板中心确认模板状态为“可使用”。

导入过程中不要关闭采集器、工作台网页或网络连接。高版本加密草稿由采集器在临时副本中自动解密，原始剪映草稿不会被修改。

## 5. 在项目中使用

1. 在模板中心找到刚导入的模板，点击“去工作台使用”；也可以在当前项目的“我的剪映模板”窗口中选择并应用。
2. 确认项目脚本行已经上传并绑定正确的人物图片。
3. 完成声音、画面生成和后处理准备。
4. 刷新动态预览，检查模板固定视觉、字幕样式和封面排版。
5. 生成剪映草稿或导出视频时，系统会：
   - 用当前项目绑定的人物图替换模板封面人物图槽；
   - 保留人物图槽原有的位置、缩放、裁剪和其他片段属性；
   - 替换正文主视频、语音、字幕和当前 BGM；
   - 保留模板原有花字、贴纸、Logo、边框、装饰和特效。

## 6. 验收标准

首次正式使用建议只选一条项目任务验证：

1. 模板中心能看到模板卡片；草稿含 `draft_cover.jpg/png` 时应显示缩略图。
2. 模板状态为“可使用”，没有待补资源提示。
3. 生成结果开头的封面时长与填写的帧数一致。
4. 封面人物已经替换为当前项目绑定的人物图，不再出现模板中的旧人物。
5. 封面的标题、花字、Logo、贴纸、边框和特效仍然存在。
6. 正文主视频、语音、字幕和 BGM 均来自当前项目。
7. 剪映时间线与最终导出 MP4 都正常后，再批量使用该模板。

## 7. 常见问题

### 模板卡片显示“暂无草稿封面”

草稿目录中没有 `draft_cover.jpg` 或 `draft_cover.png`。这只影响模板中心的缩略图展示，不等于封面人物图槽识别失败，也不阻止模板使用。

### 生成后仍出现模板中的旧人物图

优先检查：

1. 人物照片是否从第 0 帧开始；
2. 是否为普通视频轨上的照片素材；
3. 照片时长是否与导入时填写的封面帧数接近；
4. 同一个照片素材是否在草稿中被重复使用；
5. 当前项目是否已经绑定可用的人物图片。

修改剪映草稿后，需要重新导入为新模板或删除旧模板后重新导入；已经保存的模板不会自动读取源草稿后续变化。

### 页面提示“本机草稿工具未启动”

1. 启动或重启 `JianyingDraftCollector.exe`；
2. 确认采集器地址为 `http://127.0.0.1:8765`；
3. 刷新模板中心后重新扫描；
4. 仍失败时查看 `%LOCALAPPDATA%\JianyingDraftCollector\collector.log`。

### 扫描不到草稿

1. 在剪映中确认草稿名称和保存位置；
2. 确认草稿已经保存并能正常打开；
3. 返回模板中心重新点击“扫描草稿”；
4. 自定义草稿目录时，在采集器或工作台设置中重新选择草稿目录。

### 提示缺少模板资源

按页面提示补充对应剪映缓存资源。真正缺失的叠加视频、抠像结果、字体或特效资源会阻止模板进入“可使用”，以避免静默丢失视觉效果。

## 8. 使用边界

- 采集器不会自动导出视频。
- 采集器不会修改或删除原始剪映草稿。
- 模板缩略图读取和时间轴人物图槽识别是两项独立能力。
- 没有识别到人物图槽的历史模板仍按原方式使用，不会自动删除任何开头图片。
- 浏览器备用上传只能读取用户明确选择的文件；跨电脑导入优先使用本机采集器，以便收集草稿引用的本地缓存资源。
