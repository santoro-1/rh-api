# H3 多参考工作台开发约束

开始修改前完整读取 `README.md`、`DEVELOPER_GUIDE.md` 和上级目录的
`MiniMax H3多参考工作台开发文档.md`。涉及云端合同时，同时读取
`..\runninghub_mvp\AGENTS.md` 规定的文档；涉及 JYD 时读取
`D:\工作内容\轻盈健\公寓\jyd_plain_json_probe\AGENTS.md` 规定的文档。

- 本项目是第三个独立工作台，不向旧数字人或 LTX 页面增加 H3 模式。
- 第一版只支持 MiniMax H3 Ref2VA 单人物中文口播。
- 批次人物参考图为 0～5 张；不同脚本行可使用不同参考视频。
- 第六个有效图片槽只用于 `soft_chain` 的上一段裁切后最后可见帧。
- 节点 84 的 0.5 秒是生成端安全余量；不得按输入音频时长强裁 H3 成片，也不得从中间切除。
- H3 输出是模型生成的新音画对：输入 MiniMax 音频和 raw cues 只用于条件、冻结原稿与来源审计，
  最终音轨必须保留 H3 解码音轨；字幕以 H3 分段成片窗口为边界，再用 FunASR 对齐 H3 实际语音。
- 不接 SeedVR2，不保存云端 API Key 或用户密码。
- 未经用户明确授权，不发起真实付费调用、不部署生产、不修改生产数据库。
