# MiniMax H3 多参考工作台

> **当前定位（2026-08-23）**：本项目的 `8792` 页面是 H3 技术验收壳，不是正式批量入口。
> 云端生成、原生音画保存和 JYD v2 底层交接可以在这里单独验证；完整声音生成/独立审核、
> Excel/CSV 真批量、参考视频范围映射、原项目逐行回填和整批后期已经接入现有 JYD `/app/new`
> 并完成本地 mock 验收，尚未部署生产或执行新增真实付费验收。
> 权威清单见 `../MiniMax H3多参考工作台开发文档.md` 第 19 节。

这是数字人网站体系内的第三套独立本地工作台。第一版只做 H3 Ref2VA 单人物中文口播，复用
云端登录、MiniMax 完整语音与 raw cues、RunningHub 多账号安全原语，以及 JYD 后期合同。

当前已完成本地核心与第一版独立网页：

- 稳定项目输入合同（批次 0～5 张人物图、逐行参考视频、脚本与音频）；
- 基于 raw cues 的自动分段规划；
- `fast` / `soft_chain` 依赖调度规则；
- 0.5 秒生成安全余量与 H3 完整成片尾帧抽取合同；
- JYD `h3.jyd_handoff.v2` 实际交接：保留并合并 H3 原生音画，另为 JYD 的分轨时间线生成
  从 0 秒开始的静音基础视频和 H3 权威音频；MiniMax 输入音频/raw cues 只保留为来源审计，
  字幕以 H3 实际分段窗口为硬边界，再由 FunASR 对齐 H3 成片语音；
- 独立本地页面，支持登录、项目保存、0～5 张共享人物图、逐行参考视频、
  当前账号待审核 MiniMax 音频选择与受保护试听、自动冻结台词和音频版本、逐行覆盖补充方向/
  衔接/比例/清晰度、H3 账号选择、费用预览、明确确认、状态轮询，以及成片完成后一键
  “进入 JYD 自动后期”；
- 费用快照与项目输入绑定：待确认时修改素材或生成参数会强制作废旧报价，付费提交后锁定
  费用相关输入；已上传云端的素材不会在本地上传目录保留临时副本；
- 成功段主动重生成：先预览受影响段号和预计费用，再明确确认；`soft_chain` 下游结果失效后
  等待新尾帧逐段解锁，旧文件保留在任务历史目录。
- 失败段人工重试：普通失败或取消明确显示预计 1 次重新提交费用；远端已经成功但本地下载失败
  时只重新下载并显示 0 次新调用，重复确认不会重复入队。
- 运行中分段可显式取消；本地待提交任务直接取消，已提交任务同时尝试取消对应 RunningHub
  远端任务，取消完成后可重新预览费用再重试。

当前网页的“添加一行”只证明多行数据合同，不等于生产批量化；“进入 JYD 自动后期”当前按行
创建临时独立项目，不等于回填原 JYD 批次。测试时必须按下方临时路径操作，不能据此宣称完整
JYD 工作台已经接入。

JYD 交接使用可校验的稳定 `handoff_id`：同一组 H3 分段重复或并发点击会返回已经创建的 JYD
项目，不会生成重复项目；项目、H3 权威音频、H3 分段字幕窗口、静音基础视频和外部关联在一个事务中写入，
中途失败整体回滚。主动重生成得到新的分段 ID 后会新建后期项目，避免覆盖已经进行的剪辑。

双击 `启动H3工作台.cmd`，默认打开 `http://127.0.0.1:8792`。本地只在内存中
保存登录令牌，不保存网站密码、RunningHub Key 或 workflowId。

## 本地真实联调

本项目尚未部署生产时，不要直接双击默认启动项连接线上站点。先双击相邻
`runninghub_mvp/启动系统.cmd`，等待本地数字人网站与 Worker 启动；再在 PowerShell 中运行：

```powershell
cd D:\工作内容\轻盈健\数字人\h3_video_workbench
$env:H3_CLOUD_BASE_URL='http://127.0.0.1:8000'
.\启动H3工作台.cmd
```

浏览器打开 `http://127.0.0.1:8792` 后，页面左上角应显示
`http://127.0.0.1:8000`。使用本地数字人网站账号登录。在数字人网站管理员页面
`/admin/runninghub-pool` 给执行账号启用 H3 能力，配置已发布的 H3 Workflow ID、实例、并发和
访问密码，并授权当前测试账号。工作台列出当前账号音频和 raw cues 完整的 MiniMax 完整音频，
包括等待审核以及已经审核通过的历史音频；历史音频可重复用于 H3，不会重新合成或产生 MiniMax
费用。列表为空时，需要先在既有语音流程生成一条完整音频。

正常验收顺序是：新建项目、选择人物图（可为 0 张）、逐行上传参考视频并选择 MiniMax 音频、
试听后点击“试听后审核声音”、选择执行账号、点击“计算分段与费用”。声音审核不创建 H3 任务，
计算费用也不会提交 RunningHub；核对预计付费调用次数后，再点击“确认费用并开始”。H3 费用
确认不会顺带批准待审核声音。每个成功分段都会显示“下载验收视频”，可在进入 JYD 前检查 H3 原生
音画、口型和完整尾部。全部分段成功后再点击“进入 JYD 自动后期”。

云端 H3 图构造与 raw-workflow 适配器位于相邻项目 `runninghub_mvp`。JYD 导入器位于
`jyd_plain_json_probe/src/jyd_probe/h3_handoff.py`。当前自动化测试全部使用本地对象和 mock，
不会发起 MiniMax、RunningHub 或剪映付费调用。

```powershell
cd D:\工作内容\轻盈健\数字人\h3_video_workbench
$env:PYTHONPATH='src'
python -m pytest -q
```
